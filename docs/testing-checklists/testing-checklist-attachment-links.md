# Чеклист тестирования: привязка вложений к гипотезам и фичам

**Требование**: `NEW Привязка вложений к гипотезам и фичам`  
**Дата тестирования**: _______________

## Предварительные условия

- [ ] Пользователь авторизован, есть продукт
- [ ] Миграции вложений и junction-таблиц применены
- [ ] Есть хотя бы одна сохранённая гипотеза и одна сохранённая фича
- [ ] В библиотеке можно загрузить тестовый файл (не исполняемый, < 10 МБ)

---

## Сценарий 1: Попап только у сохранённой сущности

1. [ ] New Hypothesis — кнопки Attachments нет
2. [ ] Сохранить гипотезу, открыть снова — кнопка Attachments есть
3. [ ] New Feature на доске — кнопки Attachments нет
4. [ ] Сохранённая фича — кнопка есть

---

## Сценарий 2: Прикрепить из библиотеки и отцепить

1. [ ] Загрузить файл на странице Attachments
2. [ ] В редакторе гипотезы открыть Attachments, Attach этот файл
3. [ ] Файл в секции Attached; в библиотеке бейдж Hypotheses
4. [ ] Detach — файл пропал из попапа, в библиотеке остался, бейдж Hypotheses исчез
5. [ ] Закрытие попапа не закрывает редактор гипотезы

---

## Сценарий 3: Загрузка из попапа и дедуп

1. [ ] Из попапа гипотезы Upload нового файла — файл в библиотеке и прикреплён
2. [ ] Upload того же файла ещё раз — новый объект не создаётся, файл остаётся прикреплённым (тост про existing / attached)
3. [ ] Из попапа нельзя удалить файл из продукта

---

## Сценарий 4: Фича

1. [ ] Прикрепить тот же или другой файл к фиче
2. [ ] В библиотеке бейдж Features (и Hypotheses, если файл на обеих)
3. [ ] Detach на фиче не снимает связь с гипотезой

---

## Сценарий 5: Удаление из библиотеки

1. [ ] Файл прикреплён к гипотезе и к фиче
2. [ ] Удалить на странице Attachments
3. [ ] Попапы гипотезы и фичи больше не показывают этот файл

---

## Сценарий 6: Наследование

1. [ ] Гипотеза с вложениями → Clone — у клона те же файлы, в Storage без дубля
2. [ ] Create Feature from Hypothesis — у новой фичи те же вложения
3. [ ] Discover this feature у фичи с вложениями — у новой гипотезы те же вложения
4. [ ] Сменить Linked Hypothesis в редакторе фичи — список вложений фичи не меняется

---

## Сценарий 7: Удаление сущности

1. [ ] Удалить гипотезу с вложениями — файлы остаются в библиотеке
2. [ ] Удалить фичу с вложениями — файлы остаются в библиотеке
